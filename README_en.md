# ComfortableKULMS

A browser extension for making KULMS more comfortable to use.  
Target site: `https://lms.gakusei.kyoto-u.ac.jp/portal`

## Readme
English | [Japanese](https://github.com/MAV3Ndev/ComfortableKULMS/blob/master/README.md)

## About This Fork

This repository is a fork of [das08/ComfortablePandA](https://github.com/das08/ComfortablePandA), adjusted for Kyoto University's newer LMS, KULMS.  
This fork uses coding assistance tools such as Claude Code and Codex. Because the output may still contain AI slop, I do not plan to open a PR to the upstream repository for now.

Main changes in this fork:

- Updated the target URL to KULMS
- Adjusted miniSakai injection points and course discovery for the newer KULMS portal UI
- Updated unread badges and color-coding to match the KULMS sidebar structure

## Usage

1. Load the extension in your browser
2. Log in to KULMS
3. Open miniSakai from the button added near the top-right area

## Installation

Download the ZIP from Releases and load it as an unpacked extension.
